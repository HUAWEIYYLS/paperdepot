# 论文摘要生成规范

你要为一篇学术论文生成结构化的中文摘要和四类标签。这是科研知识库，**质量优先于速度**。

## 输入

1. **digest 文件**（`cache/digests/*.digest.md`，或插件传入的 digest）—— 已提取的元数据、章节结构、图注、正文主体
2. **完整正文**（可选）—— `<条目目录>/full.md`，MinerU 解析结果

**如果 digest 里标注了「中间省略 N 字符」，而摘要需要该部分的信息，请直接读同目录的 `full.md`。**
数字、结论、方法细节必须以原文为准，宁可多读也不许编造。

## 输出：在条目目录下写两个文件

### 1. `summary.md`

```
---
title: "论文标题"
source: "DOI 或 arXiv 号"
created: "日期"
---

# 📖 论文摘要

## 一句话总结

> 用一句话概括这篇论文的核心贡献。

## 研究背景

- **问题重要性**: 这个问题为什么重要
- **技术难点**: 难在哪里

## 研究方法

### 核心思路

> 用通俗的话解释这篇论文做了什么、怎么做的。

### 原理详解

- **核心原理**：用通俗语言解释核心思想（可用类比）
- **数学/算法逻辑**：关键公式及其直观含义
- **与已有方法的关系**：改进了什么，比之前好在哪

### 关键步骤

1. **步骤名** — 做什么 + 为什么
2. ...

## 主要结果

| 指标 | 结果 |
|------|------|
| ... | ... |

## 结论与贡献

1. **贡献项** — 描述
2. ...

## 📊 关键数据汇总

| 参数 | 值 |
|------|----|
| ... | ... |

## 📈 论文结构

1. 章节名 — 一句话说明
2. ...
```

### 2. `tags.md`

```
# <论文标题> - 标签

## 研究领域
- 标签1
- 标签2

## 技术方法
- 标签1
- 标签2

## 应用场景
- 标签1
- 标签2

## 仪器设备
- 标签1
- 标签2
```

## 标签规则

- 每类至少 2 个，**中文**，必要时附英文原名（如「绝热拉锥 (adiabatic tapering)」）
- **优先复用项目已有词汇**：
  - 研究领域：天文光纤光谱处理、光谱学、数据处理、光纤光学、天文仪器、时域天文学、恒星物理
  - 技术方法：光谱提取、轮廓拟合、FRD、焦比退化、模态噪声、光纤扰频、模式展开、EEM、频域滤波、光纤串扰、光子灯笼、CCF、端到端仿真、反卷积、盲反卷积、Richardson-Lucy、PSF重构、深度学习
  - 仪器设备：LAMOST、光纤光谱仪、CCD、TESS、ZTF、Gaia、SDSS、DESI、MUSE、HETDEX、JWST
- 只有确实需要时才新增标签

## 质量红线

- ❌ 不许编造数据、作者、期刊、结论
- ❌ 不许把「论文说了」写成「我认为」
- ✅ 数字必须能在原文找到
- ✅ 方法部分用通俗语言（读者是同行但不熟悉该具体方向）
- ✅ 全文中文，专业术语保留英文原名
- ✅ 公式用 LaTeX：`$$...$$` 或 `$...$`

## 完成后回复

只需三行：
1. summary.md 汉字数
2. 标签总数 + 新增标签列表（不在上面词汇表里的）
3. 是否读过 full.md 补充细节
